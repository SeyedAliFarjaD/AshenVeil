### CDP test-harness gotcha (cost 4 debug cycles — IMPORTANT)

`Phaser.Geom.Intersects.RectangleToRectangle(rectA, rectB)` reads `.right` / `.bottom`
getters. Passing a PLAIN OBJECT `{x,y,width,height}` as rectA makes those `undefined`, so the
"enemy is right/below the rect" rejection never fires → the strike hits EVERY enemy not
left-of/above the rect. Symptom: damage ledger shows unrelated enemies losing HP.
**Always build test rects with `new Phaser.Geom.Rectangle(...)`** (Phaser is a page global).
Second gotcha: `sprite.setPosition()` does NOT move an arcade body until the next physics
step — use `body.reset(x, y)` when a test needs immediate body placement.

## Test-harness lessons (new, cost cycles)

1. **`body.reset(x, y)` does NOT put the arcade body's top-left at (x, y)** — for a hollow it
   landed 32px left and 60px up. Never position enemies with `reset` and assume the body
   followed. Instead build the strike rect around `g.bodyRect(enemy)` and leave the enemy
   where it is.
2. `text.color` on a Phaser Text is **null**; the real colour lives in `.style.color`.
3. `Scene.isPaused()` is false while the bonfire menu is open — `setPaused()` only sets
   `g.paused` + pauses physics/anims/tweens. Assert `g.paused` / `physics.world.isPaused`.
4. On a `Scene` instance, `scene.scene` is the ScenePlugin (`get`, not `getScene`). Use
   `window.__game.scene.getScene('UI')` for cross-scene lookups.
5. Pressing Enter on the Title with an existing save **continues that save and ignores
   `?level=N`**. Emit `{code:'KeyN'}` for a fresh run when a specific level is required.
6. A Soul Bolt read a tick after `startCast()` can already be gone (it flew into an enemy).
   Read `soulBolts` in the same synchronous eval that casts.
7. To assert a value computed inside a method without depending on world state, monkey-patch
   the method (`g.playerStrike = fn`) to capture the argument, then restore it.
